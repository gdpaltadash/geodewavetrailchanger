# Percent Wave Trail

Set the wave trail color from a chosen percent onward, separately for Player 1 and Player 2.

- Before the first stop the wave uses your normal icon wave color.
- Works from StartPos (the percent is read from the player's position).
- The color depends only on the current percent, so leaving and re-entering the wave keeps the same colors.
- Open the editor from the pause menu button or the main menu button, edit rows, press **Apply**.
